Fabric AI Tools

Meeting Follow-Up Drafter

Jot a few notes after a meeting. Get a ready-to-send follow-up in your Gmail Drafts within 30 minutes.

How it works

During / after meeting Email yourself with subject
MTG: Meeting Name
→
Within 30 min A draft appears in Gmail Drafts — summary, decisions, action items, pre-addressed to all attendees
→
Review & send Open Drafts, tweak anything, hit Send
⏱ Setup takes about 5 minutes

Before you start — you'll need

Python 3.10+ — python.org/downloads. During install, check "Add Python to PATH".
Claude Code — claude.ai/download. Sign in with your Anthropic account.
Google credentials file — a file named client_secret_*.json. Ari will send this to you — don't skip this, the tool won't run without it.
1

Download the files

Get all the scripts onto your machine

Option A — Download ZIP (simplest, no git required)
Download ZIP from GitHub

Unzip and move the claude_101-main folder to your Desktop. Rename it my-agent.

Option B — Clone with git (if you have git installed)
cd %USERPROFILE%\Desktop
git clone https://github.com/arikellman/claude_101.git my-agent
2

Add the credentials file

Drop the file Ari sent you into the my-agent folder

Place the file here:

C:\Users\[your username]\Desktop\my-agent\client_secret_*.json

It should sit alongside google_auth.py, run_auth.py, etc. The filename starts with client_secret_ — don't rename it.

Don't have this file? Ask Ari — he'll send it directly. It can't be shared via GitHub for security reasons.
3

Run the setup

One double-click installs everything and authenticates your Google account

Double-click this file inside my-agent:

📄 meeting-followup-setup.bat

It will automatically:

  1. Install required Python packages
  2. Open a browser — sign in with your Fabric Google account and click Allow
  3. Scan your sent mail once to learn your writing style
Browser didn't open? Check your terminal — the auth URL will be printed there. Copy and paste it into your browser manually.
4

Schedule the agent

Tell Claude Code to check for new meeting notes every 30 minutes

Open Claude Code, then run:
/schedule

When asked what the task should do, paste this prompt and tell it to run every 30 minutes:

Run the meeting follow-up processor for Avi Jacoby.

cd /d "%USERPROFILE%\Desktop\my-agent"
python -m meeting_followup.process_meeting fetch

Follow the steps in meeting_followup\scheduled_prompt.md to process any new meetings found. Report a summary when done.
Claude Code needs to be running for the scheduled agent to fire. It works the same way as your morning briefing agent.

How to use it every day

During or after any meeting, email yourself. The subject line is the trigger.

To:avi.jacoby@getfabric.com
Subject:MTG: Budget Review with Finance
Discussed Q3 forecast variance.
Agreed to move $200k from opex to capex.
Sarah to update the model by Friday.
Need to revisit headcount assumptions next week.

CC: sarah.chen@getfabric.com ← optional: CC someone not on the calendar invite

Within 30 minutes, a draft appears in your Gmail Drafts, pre-addressed to all meeting attendees. Open it, make any edits, and hit Send. If you don't need a follow-up for a given meeting, just delete the draft.

Auto-skipped: Fabric IL Weekly and any calendar events with no other participants (solo blocks, focus time, etc.) are ignored automatically.

Files reference

What's in the my-agent folder and what each file does

File Purpose
meeting_followup/scheduled_prompt.md Claude's instructions — what the agent reads and follows every 30 min
meeting_followup/process_meeting.py Mechanics — fetches emails, looks up calendar, creates Gmail drafts, tracks state
meeting_followup/jack_style_profile.md Your writing style — edit this any time to adjust tone or format
gmail_send.py / gmail_search.py Gmail utilities used by the agent
google_auth.py / run_auth.py Google authentication — run once during setup
meeting_followup/state.json Tracks processed emails so nothing runs twice — don't edit manually
