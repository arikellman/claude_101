Fabric AI Tools

Meeting Follow-Up Drafter

Send a quick email after a meeting. Get a ready-to-send draft back within 30 minutes.

How it works

During / after meeting Email yourself with subject
MTG: Meeting Name
→
Within 30 min A draft follow-up appears in your Gmail Drafts — summary, decisions, action items, pre-addressed to all attendees
→
Review & send Open Drafts, tweak anything you like, hit Send
⏱ Setup takes about 10 minutes
Before you start: You need the my-agent folder on your machine with the morning briefing already working. If you haven't done that yet, do that first.
1

Get the latest files

Pull the new meeting follow-up scripts into your existing setup

Open a terminal in your my-agent folder and run:
git pull

This downloads the new meeting_followup/ folder and all its scripts.

2

Install one new package

The AI drafting uses the Anthropic SDK

In the same terminal:
pip install anthropic
3

Add your Anthropic API key

The drafter calls Claude to write the follow-up email

Get your key

Go to console.anthropic.com → API Keys → Create Key. Copy the key (starts with sk-ant-).

Set it as an environment variable (run in terminal, replace with your key):
setx ANTHROPIC_API_KEY "sk-ant-YOUR-KEY-HERE"

Close and reopen your terminal after running this — the variable won't be active until you do.

4

Re-authenticate Google

The tool now needs access to your Google Calendar — takes 30 seconds

Delete the old token and re-auth:
del google_token.json
python run_auth.py

A browser window opens. Sign in with your Fabric Google account and click Allow on all permissions. Come back here when done.

Why? Calendar access was added so the tool can look up who was in each meeting automatically — you don't have to list attendees yourself.
5

Build your style profile

Scans your sent mail once so drafts sound like you — never runs again

Run from your my-agent folder:
python -m meeting_followup.style_init

Takes about 15 seconds. Creates a meeting_followup/jack_style_profile.md file that the drafter uses every time. You can edit this file manually if you want to tweak the style.

6

Schedule the agent

Set it to run every 30 minutes — just like your morning briefing

In Claude Code, run:
/schedule

When Claude asks what the task should do, paste this prompt:

Run the meeting follow-up processor for Avi Jacoby.

Working directory: C:\Users\[YOUR-USERNAME]\Desktop\my-agent
(Replace [YOUR-USERNAME] with your actual Windows username)

Run:
python -m meeting_followup.process_meeting

Report the output. If there are errors, report them clearly but do not fix code automatically.

Tell it to run every 30 minutes.

Replace [YOUR-USERNAME] with your actual Windows username (e.g., avi.jacoby). You can confirm it by running echo %USERNAME% in a terminal.

How to use it every day

Email yourself during or after any meeting. The subject line is the only thing that matters.

To:avi.jacoby@getfabric.com
Subject:MTG: Budget Review with Finance
Discussed Q3 forecast variance.
Agreed to move $200k from opex to capex.
Sarah to update the model by Friday.
Need to revisit headcount assumptions next week.

CC: sarah.chen@getfabric.com ← optional: add anyone not on the invite

Within 30 minutes, a draft appears in your Gmail Drafts, pre-addressed to all meeting attendees. Open it, make any edits you want, and hit Send. If you don't need a follow-up, just delete the draft.

Auto-skipped meetings: Fabric IL Weekly and any calendar events with no other participants (solo blocks, focus time, etc.) are ignored automatically. No follow-up will be drafted for those.

Files reference

What was installed and what each file does

File Purpose
meeting_followup/process_meeting.py Main processor — runs every 30 min, handles everything
meeting_followup/style_init.py One-time style scanner — run once during setup
meeting_followup/jack_style_profile.md Your style guide — edit this to adjust tone and format
meeting_followup/calendar_utils.py Looks up meeting attendees from Google Calendar
meeting_followup/state.json Tracks which emails have been processed — don't edit manually
