Meeting Follow-Up Drafter

Jot a few notes after a meeting. Get a ready-to-send follow-up in your Gmail Drafts within 30 minutes.

How it works

During / after meeting Email yourself with subject
MTG: Meeting Name
→
Within 30 min A draft appears in Gmail Drafts — summary, decisions, action items, pre-addressed to all attendees
→
Review & send Open Drafts, tweak anything, hit Send
⏱ Setup takes about 2 minutes
Requires your morning briefing agent to already be running. This tool reuses the same Google credentials, Python packages, and Calendar MCP you already have — no new authentication or installs needed.
1

Get the files

Pull the new folder into your existing my-agent directory

In a terminal inside your my-agent folder:
git pull

This adds the meeting_followup/ folder. That's all that's new — everything else (Gmail, Google auth, packages) is already in place.

2

Build your style profile

Scans your sent mail once — never needs to run again

Option A — Double-click:

📄 meeting-followup-setup.bat

Scans your sent mail and saves your style profile automatically.

Option B — Run in terminal:
python -m meeting_followup.style_init

Takes about 15 seconds. Creates meeting_followup/jack_style_profile.md — you can edit this file any time to adjust tone or format.

3

Schedule the agent

Runs every 30 minutes alongside your morning briefing

In Claude Code, run:
/schedule

When asked what the task should do, paste this prompt and tell it to run every 30 minutes:

Run the meeting follow-up processor for Avi Jacoby.

cd /d "%USERPROFILE%\Desktop\my-agent"
python -m meeting_followup.process_meeting fetch

Follow the steps in meeting_followup\scheduled_prompt.md to process any new meetings found. Report a summary when done.

How to use it every day

During or after any meeting, email yourself. The subject line is the only thing that matters.

To:avi.jacoby@getfabric.com
Subject:MTG: Budget Review with Finance
Discussed Q3 forecast variance.
Agreed to move $200k from opex to capex.
Sarah to update the model by Friday.
Need to revisit headcount assumptions next week.

CC: sarah.chen@getfabric.com ← optional: CC someone not on the calendar invite

Within 30 minutes, a draft appears in your Gmail Drafts, pre-addressed to all meeting attendees. Open it, make any edits, hit Send. Don't need a follow-up? Just delete the draft.

Auto-skipped: Fabric IL Weekly and any events with no other participants (solo blocks, focus time) are ignored automatically — no draft will be created for those.

Files reference

What's in the meeting_followup/ folder

File Purpose
scheduled_prompt.md Claude's instructions — what the agent reads and follows every 30 min
process_meeting.py Mechanics — fetches emails, creates Gmail drafts, tracks state
jack_style_profile.md Your writing style — edit any time to adjust tone or format
style_init.py One-time style scanner — re-run any time to refresh
state.json Tracks processed emails so nothing runs twice — don't edit manually
